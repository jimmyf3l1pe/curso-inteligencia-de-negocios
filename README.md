## 📌 Sobre o Projeto

Este repositório foi criado para apoiar o curso de **Business Intelligence aplicado à Segurança Pública**, com foco em análise de dados, construção de indicadores estratégicos e apoio à tomada de decisão operacional e gerencial.

O projeto foi desenvolvido para permitir que alunos tenham contato com problemas reais de negócio, utilizando bases estruturadas e ferramentas modernas de análise de dados.

---

## 🎯 Objetivos de Aprendizagem

Ao final do curso, o aluno será capaz de:

✔ Coletar, organizar e tratar dados operacionais  
✔ Criar indicadores estratégicos (KPIs)  
✔ Desenvolver consultas SQL para análise investigativa  
✔ Construir dashboards interativos  
✔ Aplicar BI em cenários de gestão pública e segurança pública  
✔ Apoiar processos de tomada de decisão baseada em evidências
